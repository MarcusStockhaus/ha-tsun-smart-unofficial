# Security / Sicherheit

**EN** – Please report vulnerabilities privately via GitHub *Security → Report a vulnerability* instead of a public issue.
Never post tokens, password hashes, serial numbers, addresses or unredacted diagnostics in issues.

**DE** – Bitte melde Sicherheitslücken privat über GitHub *Security → Report a vulnerability* statt in einem öffentlichen Issue.
Poste niemals Tokens, Passwort-Hashes, Seriennummern, Adressen oder ungeschwärzte Diagnosedaten in Issues.
